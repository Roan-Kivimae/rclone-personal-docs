# Personal rclone privacy policy

Last updated: 17 November 2026.

## Scope

This policy describes a personal, single-account rclone configuration on a Workstation, Server, Mac mini and Windows Laptop.
The owner uses it for selected transfers involving their Google Drive account and selected devices.
It is not a public service for other users.

## Data and purpose

The owner approved Google Drive permission to see, edit, create and delete files.
Rclone uses file contents and related metadata as needed for the operations the owner selects.
Metadata can include file names, sizes, modification times and checksums.
OAuth credentials and tokens let rclone access the approved account.

The current setup test used one owner-selected 43-byte file.
This configuration does not read the owner's email, calendar, messages or recordings as separate connected services.
It does not automatically select those sources for transfer.

## Storage and sharing

Google Drive and the owner-selected source and destination devices are the intended storage and transfer endpoints.
Files can leave a source device when the owner selects a transfer.
The configuration does not sell file data, use it for advertising or share it with unrequested third parties.

Google processes data through its services under the [Google Privacy Policy](https://policies.google.com/privacy).
Google API access is governed by the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy).

## Owner controls and retention

The owner chooses operations, source paths and destinations. The owner can stop a transfer and remove a configured connection.
The owner can revoke the client's access through [Google Account connections](https://myaccount.google.com/connections).
Revocation stops future authorized API access through that grant. It does not delete copies already transferred.

Transferred files remain at their storage locations until the owner removes them or the relevant storage service applies its retention rules.
This configuration has no separate fixed retention period for those files.
Operational logs can contain transfer metadata. The owner manages local logs and saved configuration files on the devices.
This policy does not promise a particular automatic log-deletion period.

## Documentation website

If these documents are published with GitHub Pages, GitHub hosts the public pages.
GitHub Pages records visitor IP addresses for security, as described in [GitHub's Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).
No custom analytics, advertising or data-entry form is included in these documents.
Private account identifiers, credentials and transferred file contents are not included in these public documents.

## Changes and requests

The owner controls this personal configuration and its data. They can change or discontinue it through the device and Google Account controls described above.
Any material change in its purpose or data use requires a corresponding policy update.
